## 这是什么

Maggnn AI 是一个**全品类命理 + AI 咨询平台**。

我们做了一件事：把命理学里最扎实的部分——**精确排盘**——交给经过验证的传统算法，把**解读与洞察**交给大模型，让你在任何时候打开网页，都能得到一份既专业、又能看懂的答案。

不需要懂术语。输入出生信息，剩下的交给 Maggnn。

## 核心功能

### 命理工具

- **八字排盘** — 四柱、十神、藏干、五行强弱、大运流年，支持真太阳时修正
- **紫微斗数** — 十二宫、十四主星、四化飞星、三方四正
- **梅花易数** — 时间起卦 / 数字起卦，体用互变，万物类象
- **万年历 / 黄历** — 公农历互查、干支、宜忌、吉时
- **运势趋势** — 人生起伏曲线可视化，一眼看清大运走向

### AI 咨询助手「小麦」

- **三种模式**：快速问答 / 深度思考 / 专家级解读，按需切换
- **流式输出**：答案逐字出现，不用干等
- **追问不停**：多话题并行对话，随时深挖任意细节
- **游客免费额度**：不注册也能先体验

### 心理测评

- **MBTI** 三档题量（200 / 90 / 16 题），完整报告 + 雷达图
- **IQ mini**、**多元天赋**、**色彩人格**
- 测评结果可与命盘互相印证，得到更立体的自我画像

### 关系分析

- 恋爱、合伙、亲子、朋友——**双盘合参**
- 匹配度评分、关系图谱、逐项解读：沟通、价值观、潜在冲突与互补建议
- 帮你在重要关系里，看见看不见的那一面

### 更多

- **报告可分享**：命盘与报告一键生成精美分享页
- **社区**：命理爱好者交流动态
- **会员订阅 + 积分**：按需选择月度 / 年度方案，工具用量灵活可控
- **兑换码**：福利、礼品卡一键兑换
